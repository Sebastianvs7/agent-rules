# Translation Rules

Load when the project has i18n and you are adding, changing, moving, or removing user-facing text. Skip this file if the project has no translation catalog.

## Rules

- When adding or changing user-facing text, add it to the project's i18n catalog.
- Do not hardcode UI copy directly inside components.
- Reuse existing translation keys when the meaning is the same.
- Create clear, scoped translation keys when adding new text.

## Self-Check

- New user-facing text is present in the project's i18n catalog.
- Existing keys are reused when the meaning matches.
- Translation keys are scoped and understandable.
- No new hardcoded UI copy remains in components.
